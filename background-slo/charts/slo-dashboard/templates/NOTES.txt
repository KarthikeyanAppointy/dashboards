1. Get the application URL:

{{- if .Values.istio.enabled }}
  The application is exposed via Istio Gateway.
  If using a local Kubernetes cluster with Istio ingressgateway, run:
  kubectl port-forward -n istio-system svc/istio-ingressgateway 8080:80

  Then access: http://localhost:8080

  For production, configure your DNS to point to the Istio ingress gateway's
  external IP and access via the configured hosts.

{{- else if .Values.ingress.enabled }}
  {{- range $host := .Values.ingress.hosts }}
    {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
    {{- end }}
  {{- end }}
{{- else }}
  The frontend service is ClusterIP type. To access it, use port-forwarding:
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "slo-dashboard.fullname" . }} 8080:80

  Then access: http://localhost:8080
{{- end }}

2. Connect to the database:
   The database URL is stored in the secret "{{ include "slo-dashboard.fullname" . }}-secret".
   To retrieve it:
   kubectl get secret --namespace {{ .Release.Namespace }} {{ include "slo-dashboard.fullname" . }}-secret \
     -o jsonpath="{.data.DATABASE_URL}" | base64 -d
   echo ""
